# Bank Customer Churn Analysis – Power BI

## Project Overview
An interactive Power BI project analyzing customer churn and retention patterns in the banking domain.

## Tools & Technologies
- Power BI
- SQL
- DAX
- Power Query
- Excel

## Key Analysis
- Customer churn and retention analysis
- Churn by gender and geography
- Credit score comparison
- Product usage analysis
- Customer segmentation
- Key performance indicators

## Key Insights
- Female churn rate: 25.05%
- Male churn rate: 15.37%
- Average credit score of retained customers: 652
- Average credit score of exited customers: 645

## Dashboard
Interactive Power BI dashboard with KPIs, slicers, and visualizations for analyzing customer churn.

## Skills Demonstrated
Data Cleaning | SQL Analysis | Power Query | DAX | Data Visualization | Business Insights
